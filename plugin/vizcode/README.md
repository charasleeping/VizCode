# VizCode for CodeRunner

VizCode adds a visual editor and live debugger to CodeRunner questions.
Install it as `local/vizcode`; CodeRunner is required.

This beta supports Moodle 4.5 / PHP 8.3, CodeRunner 5.10.9 and adaptive behaviour
1.4.8 with the supplied integration bridge. See the project README and
`docs/INSTALL.md` for complete installation instructions.
